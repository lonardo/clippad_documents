# Try OfficeAddin with Everyday Tasks / 用日常任务体验 OfficeAddin

These small scenarios help you try OfficeAddin with real Office work. They are designed to show the product's main idea: start from a clear task, review the scope, and keep control of every important change.

这些小场景帮助您用真实的 Office 工作体验 OfficeAddin。它们体现了产品的核心思路：从明确任务开始，先查看影响范围，并始终保留对重要改动的控制权。

Feature names and availability can vary by release and Office application. Use the commands and entry points available in your installed version.

功能名称和可用范围可能因版本和 Office 应用而不同。请使用您安装版本中实际可见的指令和入口。

## Before you start / 开始前

1. Use a copy of a document, workbook, or presentation that you can safely change.
2. Save the original before trying a write operation.
3. Start with one small, clear goal rather than asking for every possible improvement at once.
4. Read the preview or scope summary before confirming any change.

1. 请使用一份可以安全修改的文档、工作簿或演示文稿副本。
2. 尝试写入操作前，请先保存原件。
3. 先从一个小而明确的目标开始，不要一次要求处理所有问题。
4. 确认任何改动前，请阅读预览或影响范围摘要。

## 1. Prepare a Word document for delivery / 准备一份可交付的 Word 文档

### Prepare / 准备

Create a copy of a one-to-three-page Word document. Include a few intentionally inconsistent headings, extra blank paragraphs, or review items that you are comfortable checking.

复制一份一到三页的 Word 文档。可以保留少量不一致的标题、额外空段或您愿意检查的审阅内容。

### Try it / 试一试

Use either path below:

可任选以下一种路径：

- **Command or search:** search for an existing formatting, cleanup, review, or delivery-related command whose description exactly matches your need. Review its scope before applying it.
- **AI workbench:** describe a bounded goal, for example: “Please help prepare the current document for delivery. First show me the plan and affected scope; do not make changes yet.”

- **指令或搜索：** 搜索一个与当前需求完全匹配的排版、清理、审阅或交付相关指令。应用前先查看其影响范围。
- **AI 工作台：** 描述一个有边界的目标，例如：“请帮我把当前文档整理为可交付版本。先展示计划和影响范围，不要立即修改。”

### A good result looks like / 理想结果应当是

The product identifies the current document or selection, explains what it can check or change, and asks for confirmation before an important write. If the scope is unclear, asking a focused question is a good outcome.

产品识别当前文档或选区，说明可以检查或修改什么，并在重要写入前请求确认。如果范围不清楚，提出一个聚焦的问题也是良好结果。

### Check after the attempt / 尝试后检查

Confirm that headings, paragraphs, review items, and any output match what you expected. If they do not, stop and use the available undo, history, or backup path rather than continuing with more changes.

确认标题、段落、审阅内容和输出结果是否符合预期。若不符合，请停止继续修改，并使用可用的撤销、历史或备份方式恢复。

## 2. Inspect an Excel table before cleaning it / 清理前检查 Excel 表格

### Prepare / 准备

Copy a small worksheet with a clear header row. It can contain a few blank values, repeated entries, or inconsistent formats.

复制一个包含清晰表头的小型工作表。它可以包含少量空值、重复项或不一致的格式。

### Try it / 试一试

Select the relevant range and ask for a narrow result, such as: “Check this table for blanks, duplicates, and obvious format inconsistencies. Show a summary before changing anything.”

选中相关区域，然后提出一个明确请求，例如：“检查这个表格中的空值、重复项和明显的格式不一致。修改前先显示摘要。”

You can start from search when a suitable existing command is available, or describe the goal in the AI workbench.

如果有合适的现有指令，可以从搜索开始；也可以在 AI 工作台中直接描述目标。

### A good result looks like / 理想结果应当是

You receive a clear description of the selected range and the issues found, followed by a proposed next step. A report-only result is useful when you are still deciding how to clean the data.

您会看到对所选区域和发现问题的清晰说明，以及一个建议的下一步。当您还在决定如何清理数据时，仅生成报告同样很有价值。

## 3. Review a PowerPoint for consistency / 检查 PowerPoint 的一致性

### Prepare / 准备

Use a copy of a short presentation with a few slides. Choose one visible consistency goal, such as titles, footers, page numbers, or repeated text.

使用一份包含少量幻灯片的演示文稿副本。选择一个可见的一致性目标，例如标题、页脚、页码或重复文本。

### Try it / 试一试

Ask for an inspection first: “Review title and footer consistency in this presentation. Summarize the affected slides before proposing any changes.”

先请求检查：“检查这份演示文稿中标题和页脚的一致性。在提出任何修改前，总结受影响的幻灯片。”

### A good result looks like / 理想结果应当是

The product makes the target and scope understandable. It should not turn a simple consistency request into unrelated changes to layouts, themes, animations, or hidden slides.

产品应让目标和范围容易理解。它不应把简单的一致性请求扩大为对版式、主题、动画或隐藏幻灯片的无关修改。

## 4. Evaluate an insight without being interrupted / 在不被打断的情况下体验洞察

Insights are optional help, not a required step. If your version shows an insight while you work, try the following:

洞察是可选帮助，而不是必经步骤。如果您的版本在工作时显示洞察，可以尝试以下操作：

1. Read what the insight believes is relevant and why.
2. Decide whether the suggested next step fits the task you are actually doing.
3. Ignore it and continue your work, or act on it locally if it is useful.
4. Start a direct command or the AI workbench independently; you should not need the insight to do so.

1. 阅读洞察认为相关的内容以及原因。
2. 判断建议的下一步是否符合您真正正在做的工作。
3. 如果没有帮助，可以忽略它并继续工作；如果有帮助，可以在当前场景处理。
4. 独立启动直接指令或 AI 工作台；您不应必须依赖洞察才能完成任务。

No insight appearing is also a valid result. The product should prefer silence over an irrelevant interruption.

没有出现洞察同样是正常结果。产品应当宁可保持安静，也不要给出无关打扰。

## What to look for in every scenario / 每个场景都值得观察什么

| Look for | Why it matters |
|---|---|
| The task and affected scope are clear | You can catch a misunderstanding before a change is made |
| The next step is understandable | You can decide whether to continue without guessing |
| Important changes require your decision | You retain control of documents and files |
| The result is easy to verify | You can use the product in regular work with confidence |

| 观察点 | 为什么重要 |
|---|---|
| 任务和影响范围清晰 | 您可以在修改前发现误解 |
| 下一步容易理解 | 您无需猜测就能决定是否继续 |
| 重要改动需要您的决定 | 您始终掌控文档和文件 |
| 结果易于验证 | 您可以更放心地把产品用于日常工作 |

## Share useful feedback / 提供有价值的反馈

When sharing feedback, include the Office application, the task you were trying to complete, the result you expected, and whether the scope or next step was clear. Do not include confidential document content, private paths, credentials, or unredacted screenshots.

提交反馈时，请说明所用 Office 应用、想完成的任务、预期结果，以及影响范围或下一步是否清晰。不要提交机密文档内容、私有路径、凭据或未经脱敏的截图。
