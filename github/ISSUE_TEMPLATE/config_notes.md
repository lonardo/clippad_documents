# Issue Template Notes / Issue 模板说明

When copying to a public repository, place the YAML templates in:

复制到公共仓库时，将 YAML 模板放在：

~~~text
.github/ISSUE_TEMPLATE/config.yml
.github/ISSUE_TEMPLATE/bug_report.yml
.github/ISSUE_TEMPLATE/install_issue.yml
.github/ISSUE_TEMPLATE/feature_request.yml
.github/ISSUE_TEMPLATE/vbs_contribution.yml
.github/ISSUE_TEMPLATE/prompt_regression.yml
.github/ISSUE_TEMPLATE/documentation.yml
~~~

config_notes.md is a maintainer note and does not need to be published.

config_notes.md 是维护者说明，不必发布到公共仓库。

Product installation, bug, and feature requests belong in clippad_documents. VBS, Host, prompt, and schema contributions belong in clippad_functions.

产品安装、Bug 和功能请求放在 clippad_documents；VBS、Host、提示词和 Schema 贡献放在 clippad_functions。
