# Privacy and Data Handling / 隐私与数据处理

This is a public release summary based on the current installer strings, runtime settings, feedback path, and OfficeAddin behavior. The legally controlling policy is the policy bundled with the exact installer and the official website policy for that release.

本文档依据当前安装包协议文字、运行时设置、反馈路径和插件行为整理。具体版本安装包内置协议及官网正式隐私政策优先于本文档。

## Local Office operations / 本地 Office 操作

When a user runs a local command, OfficeAddin may read the active Word document, Excel workbook, PowerPoint presentation, current selection, local file path, or local file content needed for that command. The operation is performed on the device through Office COM and the Host runtime.

用户运行本地命令时，OfficeAddin 可能读取完成该命令所需的当前 Word 文档、Excel 工作簿、PowerPoint 演示文稿、当前选区、本地路径或本地文件内容。操作通过设备上的 Office COM 和 Host 运行时完成。

Local commands are not the same as AI or feedback requests. A script that writes a document can change local files; review preview, confirmation, backup, and rollback information before committing changes.

本地命令不等于 AI 或反馈请求。写入型脚本可能改变本地文件；提交前应查看预览、确认、备份和回滚信息。

## AI-assisted actions / AI 辅助操作

When the user explicitly invokes AI features such as summarization, translation, generation, command building, or content analysis, the product may send selected text, prompts, or limited document context to the configured AI gateway or model service. The exact provider, endpoint, retention, and account requirements are release-specific.

用户主动调用摘要、翻译、生成、指令构建或内容分析等 AI 功能时，产品可能向配置的 AI 网关或模型服务发送选中文本、提示词或有限文档上下文。具体提供商、接口、保存期限和账号要求以对应 Release 为准。

Do not use AI features with confidential, regulated, personal, or customer data unless the user and organization are authorized to do so.

除非用户和所在组织明确授权，不要用 AI 功能处理机密、受监管、个人或客户数据。

## Updates, telemetry, and diagnostics / 更新、遥测与诊断

Depending on the build and settings, the product may process:

- product version and update-check information;
- an installation identifier generated by the client;
- runtime, crash, compatibility, or health events;
- local logs or approved diagnostic attachments;
- installation and uninstall events.

根据具体版本和设置，产品可能处理：

- 产品版本和更新检查信息；
- 客户端生成的安装标识；
- 运行、崩溃、兼容性或健康状态事件；
- 本地日志或用户批准的诊断附件；
- 安装和卸载事件。

The client may store telemetry or diagnostic payloads locally before a network retry. Common local locations include:

客户端可能在网络重试前将遥测或诊断载荷暂存在本地，常见目录包括：

~~~text
%APPDATA%\OfficeAddin\Telemetry
%APPDATA%\OfficeAddin\Logs
%APPDATA%\OfficeAddin\UserProfile
~~~

Do not publish settings.ini or telemetry outbox files. They may contain endpoints, identifiers, tokens, or diagnostic content depending on the release configuration.

不要公开 settings.ini 或遥测待发送文件；根据版本配置，它们可能包含接口、标识、令牌或诊断内容。

## Feedback and community / 反馈与社区

If the user submits feedback, the selected contact field, message, product version, Office/Windows context, logs, screenshots, or attachments may be transmitted to the configured feedback service. Only attach the smallest redacted material needed for diagnosis.

用户提交反馈时，选定的联系方式、问题内容、产品版本、Office/Windows 环境、日志、截图或附件可能发送到配置的反馈服务。只应附加完成诊断所需的最小脱敏资料。

Public Issues and Discussions are public. Never post passwords, tokens, private documents, customer information, private paths, keys, or full crash dumps.

GitHub Issue 和 Discussion 是公开区域，绝不能发布密码、令牌、私有文档、客户信息、私有路径、密钥或完整崩溃转储。

## What this public repository does not contain / 公共仓库不包含什么

The public documentation repository does not contain customer documents, production credentials, server secrets, signing private keys, ICP filing materials, software-copyright filing materials, patent submissions, or private backend configuration.

公共文档仓库不包含客户文档、生产凭据、服务器密钥、签名私钥、ICP备案资料、软著申报资料、专利申报资料或私有后端配置。

## User choices / 用户选择

- Use local read-only commands for sensitive work when possible.
- Review AI context before sending it.
- Remove private fields from feedback attachments.
- Request correction or deletion through the official support channel when account data is involved.

- 敏感任务尽量使用本地只读命令。
- 发送 AI 请求前检查上下文范围。
- 上传反馈前删除隐私字段。
- 涉及账号数据时通过官方支持渠道请求更正或删除。
