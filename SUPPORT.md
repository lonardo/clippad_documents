# Support

## Before you ask

1. Read [docs/install.md](docs/install.md)
2. Read [docs/faq.md](docs/faq.md)
3. Confirm you installed the latest release
4. Close and reopen Office once after installation

## Public support channels

- GitHub Issues: install failures, bugs, feature requests
- Email: `support@clippad.cc`

## What to include

- Add-in version
- Windows version
- Office app and version
- 32-bit or 64-bit Office if known
- Steps to reproduce
- Expected vs actual result
- Screenshots or redacted logs

## Do not send

- passwords, tokens, API keys
- unredacted business documents
- personal data you are not allowed to share

## Enterprise / rollout questions

If you are evaluating deployment for a team, tell us:

- target Office channel (Microsoft 365 / LTSC / perpetual)
- whether devices are locked down by antivirus or application control
- whether users can install desktop software themselves
